# SignalX 🗼
### تطبيق إدارة أبراج الإنترنت — Flutter + Supabase + SASv4

---

## المميزات
- 📊 داشبورد مباشر للأبراج والمشتركين
- 👥 إدارة المشتركين (إضافة، تعديل، حذف، تجديد)
- 🔄 مزامنة تلقائية مع SASv4
- 💰 تتبع الدفعات (نقد / تطبيق / زين كاش)
- 📈 تقارير وإحصائيات + تصدير PDF
- 🗺 خريطة الأبراج
- 📱 بوابة المشترك
- 💾 وضع Offline كامل
- 🔔 إشعارات انتهاء الاشتراكات
- 💬 رسائل واتساب تلقائية
- 🔒 نظام تسجيل دخول بصلاحيات
- ☁️ نسخ احتياطية تلقائية

## التقنيات
- Flutter 3.x / Dart
- Supabase (قاعدة البيانات)
- SASv4 API (نظام RADIUS)
- SQLite (offline)
- Google Maps
